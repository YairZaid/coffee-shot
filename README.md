# Coffee Shot Intelligence

A data-driven platform for recording, analyzing, and experimenting with espresso
shots — built as a portfolio project.

## Status

In active development. MVP in progress — see [`docs/DECISIONS_LOG.md`](docs/DECISIONS_LOG.md)
for session-by-session progress and [`docs/CONTEXT.md`](docs/CONTEXT.md) for domain
terminology and naming decisions.

## Tech stack

- **Backend:** FastAPI (Python), PostgreSQL, Alembic
- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Infra:** Docker Compose (local dev), GitHub Actions (CI)
